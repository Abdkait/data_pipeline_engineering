Ты работаешь внутри директории учебного предмета. Нужно создать и поддерживать локальную AI-базу знаний для подготовки к контрольной работе.

Цель: сделать папку `./ai`, в которой будут храниться структурированные знания по предмету. Эта база знаний должна использоваться при разборе лекций/семинаров и при решении домашних заданий/задач.

ВАЖНО:
- Не используй папку `.ai`, используй именно `./ai`.
- Не добавляй в базу знаний всё подряд автоматически.
- Добавляй новые данные в базу знаний только когда я явно прошу:
  - “добавь в базу”
  - “обнови базу”
  - “сохрани это”
  - “запомни”
  - “обнови ai”
  - или похожая явная команда.
- Если я просто прошу решить задачу, объяснить тему или помочь с домашкой — используй базу знаний как контекст, но НЕ изменяй её.
- Если я прошу разобрать лекцию/семинар и добавить полезное в базу — тогда обновляй базу.
- Если не уверен, надо ли сохранять информацию — спроси.
- База знаний должна быть краткой, полезной и структурированной. Не копируй огромные куски исходных файлов без необходимости.
- Главная цель базы — помогать быстро решать типовые задачи и повторять теорию перед КР.

Содержание:

# AI Knowledge Base

Эта папка содержит локальную базу знаний по учебному предмету.

Она нужна для работы с LLM/Cursor:

- при разборе лекций и семинаров;
- при решении домашних заданий;
- при подготовке к контрольным и экзаменам;
- при повторении теории;
- при сохранении типовых методов решения задач.

## Главное правило

База знаний обновляется только по явной просьбе пользователя.

Если пользователь просто просит решить задачу, объяснить тему или проверить решение, нужно использовать базу знаний как контекст, но не изменять её.

## Основные файлы

- `index.md` — карта базы знаний.
- `active.md` — текущий фокус подготовки.
- `subject.md` — информация о предмете.
- `theory.md` — краткая теория по темам.
- `definitions.md` — определения.
- `formulas.md` — формулы и обозначения.
- `methods.md` — методы решения задач.
- `typical_tasks.md` — типовые задачи и шаблоны решений.
- `solved_examples.md` — разобранные примеры.
- `mistakes.md` — частые ошибки и ловушки.
- `exam_prep.md` — подготовка к КР/экзамену.
- `questions.md` — открытые вопросы.
- `sources.md` — список обработанных источников.

## Принцип работы

1. Перед ответом по предмету сначала изучи `index.md`.
2. Затем изучи `active.md`.
3. Затем открой только релевантные файлы из базы знаний.
4. Не читай все файлы подряд, если задача узкая.
5. При решении задач используй базу знаний, но не обновляй её без команды пользователя.
6. При разборе новых лекций/семинаров обновляй базу только по явной команде.

# Knowledge Base Index

## Файлы базы

### Общий контекст

- `README.md` — назначение базы знаний.
- `subject.md` — описание предмета, тем, требований.
- `active.md` — текущий фокус подготовки.

### Теория

- `theory.md` — краткая теория по темам.
- `definitions.md` — определения и важные понятия.
- `formulas.md` — формулы, обозначения, условия применимости.

### Практика

- `methods.md` — методы и алгоритмы решения задач.
- `typical_tasks.md` — типовые классы задач.
- `solved_examples.md` — разобранные примеры.
- `mistakes.md` — частые ошибки, ловушки, неверные подходы.

### Подготовка к контрольной

- `exam_prep.md` — план подготовки, чеклист, приоритеты.
- `questions.md` — открытые вопросы и слабые места.

### Источники

- `sources.md` — список обработанных лекций, семинаров, домашних заданий и других материалов.

## Правила обновления

Базу можно обновлять только если пользователь явно попросил:

- “добавь в базу”
- “обнови базу”
- “сохрани это”
- “запомни”
- “занеси в ai”
- “обнови ai”
- “добавь в knowledge base”

Если явной команды нет, не изменяй файлы базы.

## Правила сжатия

При обновлении базы:

- сохраняй только полезную информацию;
- избегай длинных цитат;
- не дублируй одно и то же в разных файлах;
- формулируй кратко;
- добавляй ссылки между разделами, если это помогает;
- сохраняй методы решения задач в виде пошаговых алгоритмов;
- сохраняй типовые ошибки отдельно в `mistakes.md`.

## Когда какой файл использовать

- Нужно понять тему → `theory.md`, `definitions.md`, `formulas.md`.
- Нужно решить задачу → `methods.md`, `typical_tasks.md`, `solved_examples.md`, `formulas.md`.
- Нужно подготовиться к КР → `exam_prep.md`, `typical_tasks.md`, `mistakes.md`, `formulas.md`.
- Нужно разобрать новый материал → `process_lecture.md` или `process_seminar.md` из папки `prompts`.
- Нужно обновить базу → `prompts/update_knowledge_base.md`.

======================== ДОПОЛНИТЕЛЬНЫЕ ИНСТРУКЦИИ ДЛЯ ТЕБЯ
После создания структуры:

Покажи дерево созданных файлов.
Кратко объясни, как теперь этим пользоваться.
Не начинай разбирать лекции или домашки, пока я не дам конкретный файл или команду.
Спроси у меня:
как называется предмет;
какие темы будут на контрольной;
какие файлы лекций/семинаров нужно разобрать первыми.
Поведение в дальнейшей работе:

Если я пишу: “разбери этот файл” — разбери, но не обновляй базу.
Если я пишу: “разбери этот файл и добавь в базу” — разбери и обнови базу.
Если я пишу: “реши задачу” — используй базу, но не обновляй её.
Если я пишу: “сохрани этот метод” — добавь метод в нужный файл.
Если я пишу: “запомни эту ошибку” — добавь её в mistakes.md.
Если я пишу: “подготовь меня к КР” — используй exam_prep.md, methods.md, typical_tasks.md, formulas.md, mistakes.md.
Теперь выполни задачу: создай папку ./ai и все перечисленные файлы с указанным содержимым.
